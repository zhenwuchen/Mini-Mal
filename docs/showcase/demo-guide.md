## 3. 3～5 分钟视频脚本

### 0:00–0:20 开场

画面：首页首屏与项目名称。

口述：这是一个基于 Next.js 的全栈微型电商项目，支付为模拟流程，
重点展示订单、支付和库存的一致性与并发保护。

### 0:20–0:50 商品与账号

画面：商品列表、分类筛选、商品详情、登录或注册。

口述：商品和分类来自 Prisma + SQLite；账户操作使用会话保护，
购物车与订单查询都按当前用户隔离。

### 0:50–1:20 购物车

画面：加入购物车、修改数量、移除、查看金额。

口述：数量与库存由服务端校验，金额从数据库当前价格重新计算。

### 1:20–1:55 创建订单

画面：选择地址、提交结算、打开订单详情。

口述：创建订单在事务中扣减库存、写订单与快照并清理购物车；
同一结算键重复提交返回原订单。

### 1:55–2:30 模拟支付成功

画面：发起支付、点击成功、看到订单变为已付款。

口述：支付金额与币种由服务端校验；订单和支付状态在同一事务更新，
其他待处理模拟支付会被取消。

### 2:30–3:00 模拟支付失败与重试

画面：新订单支付失败，再发起一次并成功。

口述：失败只影响当前支付尝试，订单仍保持待付款，库存不变化。

### 3:00–3:35 取消订单与库存恢复

画面：取消另一笔待付款订单，展示状态和库存恢复。

口述：订单取消、待处理支付取消和库存恢复在同一事务内完成；
重复取消不会重复恢复库存。

### 3:35–4:10 超时订单

画面：展示外部 Cron 配置、内部接口鉴权和扫描结果聚合。

口述：任务每分钟执行，Bearer Token 校验后按批次与时间预算扫描；
持久化游标让失败订单不会永久占住扫描起点。

### 4:10–4:40 技术总结

画面：展示站技术亮点或源码中的状态机、事务和测试名称。

口述：项目最值得展示的是支付幂等、数据库时间截止守卫、
并发完成保护、事务回滚和单实例 SQLite 的明确边界。

## 4. 录制要求

- 录屏分辨率 1920 × 1080；
- 浏览器缩放 100%；
- 终端字体足够大；
- 不展示 `.env`、Secret、Cookie、数据库文件内容；
- 完成后导出 MP4/H.264，上传到允许公开访问的视频平台；
- 展示站只引用已确认可访问的真实视频地址，不使用虚假播放器。
